## 一、项目概述

### 1\.1 项目开发背景

中华茶文化底蕴深厚，但传统茶文化传播渠道单一，线下茶馆、纸质宣传手册难以高效普及茶叶知识、茶历史、线下茶文化活动；同时茶馆线下订座流程繁琐，用户无法线上浏览茶叶、预约茶座、参与茶文化活动，商家与管理员也缺少统一线上管理平台。
为数字化推广茶文化、解决线上茶叶展示、茶活动报名、茶馆预约、用户互动、后台统一管控需求，本系统采用**SpringBoot\+Vue 前后端分离架构**开发茶文化推广平台，分为**普通用户前台**、**茶馆商家**、**系统管理员后台**三类角色，实现茶文化线上科普、茶叶展示收藏、茶活动浏览报名、茶馆茶座线上预约、评论互动、数据可视化统计一体化功能，拓宽茶文化传播渠道，简化茶馆线上运营管理流程。

### 1\.2 整体开发技术栈

#### 后端技术（SpringBoot）

1. 核心框架：SpringBoot 2\.7，标准 MVC 分层架构（Controller/Service/Mapper/Entity），统一 RESTful 接口规范

2. 持久层框架：MyBatis\-Plus，快速实现分页、多条件模糊检索、批量增删改查

3. 数据库：MySQL 8\.0，存储用户、商家、管理员、茶叶、茶活动、茶馆、茶座预约、茶史资讯、收藏、评论、发展历程全业务数据表

4. 登录鉴权：JWT 无状态 Token 认证，区分普通用户、茶馆商家、系统管理员三类角色，拦截未登录、越权访问接口

5. 文件上传模块：本地文件存储，支持茶叶封面、活动海报、用户 / 商家头像、茶馆图片上传预览

6. 安全机制：账号密码 MD5 不可逆加密存储，前后端双重表单参数校验，Token 设置固定过期时效

7. 工具依赖：Hutool 工具包，封装日期处理、加密、分页、文件处理工具

8. 可视化支持：整合 ECharts，实现活动类型饼图、茶馆预约销售柱状图数据统计

#### 前端技术（Vue3 \+ Element Plus）

1. 核心框架：Vue3 \+ VueRouter 路由管理 \+ Pinia 全局状态存储

2. UI 组件库：简约清新茶文化风格前台页面；Element Plus 组件库搭建管理员后台管理页面

3. 网络请求：Axios 全局请求 / 响应拦截器，自动携带登录 Token、捕获登录失效、统一弹窗提示异常

4. 通用封装组件：首页轮播、茶叶卡片列表、活动卡片、图片上传、富文本评论、分页搜索、详情弹窗、ECharts 可视化图表

5. 页面适配：电脑端全屏适配，操作简洁轻量化

### 1\.3 系统三类角色划分

1. **普通前台用户**
账号注册登录；浏览首页、茶叶资讯、茶活动、茶叶详情、茶馆信息、茶史发展历程；收藏心仪茶叶；线上预约茶馆茶座、完成支付；对茶叶发布评论；个人中心修改密码、更新个人信息、查看我的收藏、我的预约订单。

2. **茶馆商家**
独立商家注册入口；登录后管理自家茶馆信息、查看本店所有茶座预约订单；管理店铺茶座、订单支付状态，查看店铺销售数据。

3. **系统管理员（后台）**
全平台最高管理权限：管理所有普通用户、茶馆商家、后台管理员账号；维护茶叶分类、茶叶信息、茶文化活动、茶史发展历程；管控所有茶座预约订单；可视化统计活动、茶馆销售数据；审核管理用户茶叶评论，统一管控平台全部茶文化数据。

### 1\.4 完整业务流程梳理

1. 登录注册流程：区分**普通用户注册**、**茶馆商家注册**两套独立注册表单；前台、后台独立登录页面，登录成功签发 JWT Token，未登录无法访问个人中心、收藏、预约、评论等功能页面。

2. 普通用户前台业务流程：浏览首页茶文化轮播→查看茶叶 / 茶活动 / 茶馆详情→收藏茶叶、预约茶馆茶座、在线支付；阅读茶史发展资讯；在茶叶详情页发布评论；个人中心统一管理个人资料、收藏列表、预约订单、修改登录密码。

3. 茶馆商家业务流程：商家注册账号登录后台，维护茶馆基础信息，查看本店全部用户预约订单，处理订单支付状态，查看店铺销售统计。

4. 管理员后台运维流程：维护茶叶、茶活动、茶史、茶馆全量数据；管理平台所有用户、商家账号；查看全部茶座预约订单；通过可视化图表统计活动分类占比、茶馆销售数据；管理用户发布的茶叶评论。

### 2\.1 登录注册模块

#### 2\.1\.1 前台用户登录页面

简约海景背景登录表单，包含账号、密码输入框、记住密码勾选框、绿色登录按钮；底部提供「注册用户」跳转入口，未登录访问受限功能弹窗拦截。

#### 2\.1\.2 普通用户注册页面

必填字段：用户账号、登录密码、确认密码、用户姓名；可选上传头像、下拉选择性别、填写手机号码；前端校验密码一致性、手机号格式，后端校验账号唯一性，注册信息存入用户数据表。

#### 2\.1\.3 茶馆商家注册页面

独立商家注册表单：商家账号、密码、确认密码、商家名称、上传头像、性别、联系手机、茶馆名称；提交完成商家账号注册，绑定所属茶馆信息。

#### 2\.1\.4 管理员后台登录

独立后台登录入口，仅管理员账号可进入数据管理后台，拥有全平台数据操作权限。

### 2\.2 普通用户前台功能模块（顶部导航栏：首页、茶叶资讯、活动信息、茶叶信息、茶馆信息、茶史信息、个人中心）

#### 2\.2\.1 系统首页

顶部全屏茶文化轮播图，展示茶文化宣传海报；展示平台茶叶、热门活动快捷入口，引导用户浏览茶文化内容。

#### 2\.2\.2 活动信息模块

卡片分页展示全部茶文化线下活动，每张卡片展示活动配图、活动名称、活动时间、活动地点；分页控件支持翻页浏览全部活动，点击卡片查看活动完整详情。

#### 2\.2\.3 茶叶信息模块

1. 茶叶列表：分页展示所有茶叶卡片，点击进入茶叶详情；

2. 茶叶详情页面：展示茶叶实拍图、茶叶名称、茶叶类型、等级、品牌、产地、生产年份、收藏数量、访问点击量；右上角收藏 / 取消收藏按钮；下方分「茶叶详情」「评论」标签，支持输入文字发布茶叶评论。

#### 2\.2\.4 茶馆信息 \& 茶座预约模块

1. 茶馆列表：展示全平台所有茶馆基础信息；

#### 2\.2\.5 茶史信息（发展历程）模块

右侧侧边功能菜单栏：

4. 茶馆信息展示：查看本人所有茶馆预约订单；

5. 活动信息展示：查看本人报名参与的茶文化活动。

2. 茶馆销售统计柱状图：展示茶馆预约订单销售数据，可视化运营数据，方便管理员数据分析。

## 四、核心业务与安全流程

### 4\.1 三角色 JWT 权限鉴权流程

1. 普通用户登录：仅可访问前台页面，操作个人收藏、预约、评论，无商家、后台管理权限；

2. 茶馆商家登录：仅管理自家茶馆与本店预约订单，无法查看其他店铺、后台全局数据；

3. 管理员登录：进入后台可视化管理系统，拥有茶叶、活动、茶馆、用户、订单全量增删改查权限；

4. 后端拦截器解析 Token 内角色标识，越权访问接口直接返回 403 禁止访问；未携带有效 Token 强制跳转对应登录页面。

### 4\.2 茶叶浏览、收藏、评论业务流程

1. 用户前台浏览茶叶列表，点击进入茶叶详情查看完整图文参数；

2. 点击收藏按钮生成收藏记录，存入收藏表，个人中心我的收藏统一管理；

3. 在评论输入框提交文字评论，所有用户可在茶叶详情页查看全部评论互动内容。

### 4\.3 茶馆茶座预约 \& 支付流程

1. 用户浏览茶馆列表，选择茶馆提交茶座预约，生成预约订单；

2. 订单分为「未支付 / 已支付」两种状态，未支付订单支持线上付款；

3. 商家、管理员可查看对应店铺 / 全平台所有预约订单，统计销售数据。

### 4\.4 茶文化活动浏览业务流程

管理员后台录入线下茶文化活动信息，前台用户分页浏览活动卡片，查看活动时间、地点、详情，用户可报名参与活动，个人中心查看已报名活动。

## 五、项目部署说明

### 5\.1 SpringBoot 后端部署步骤

1. 执行项目 SQL 初始化脚本，批量创建全部数据表，预置管理员测试账号；

2. 修改`application.yml`核心配置文件：

    - MySQL 数据库连接地址、账号、密码；

    - JWT 加密密钥、Token 过期有效时长；

    - 图片文件本地上传存储路径、文件大小、格式限制；

    - ECharts 可视化数据接口配置；

    - 后端服务启动端口（默认 8080）；

3. Maven 打包命令：`mvn clean package -DskipTests` 生成可执行 Jar 包；

4. 服务器运行命令：`java -jar tea-culture-system.jar`。

### 5\.2 Vue 前端部署步骤

1. 前端项目根目录执行 `npm install` 安装全部项目依赖；

2. 修改 Axios 全局请求基地址，指向后端服务接口地址；

3. 生产环境打包静态资源：`npm run build` 输出 dist 文件夹；

4. Nginx 托管 dist 静态页面，配置 /api 反向代理转发至后端 8080 端口；

5. 路由区分普通用户前台、商家端、管理员后台三套独立访问入口。

## 六、系统特色与创新亮点

### 6\.1 业务功能亮点

1. **茶文化数字化科普载体**：整合茶叶百科、茶史发展、线下茶活动三大科普模块，线上全方位推广传统茶文化；

2. **多角色分层运营体系**：普通用户、茶馆商家、管理员三类角色权责清晰，适配茶文化传播 \+ 茶馆线上运营双重场景；

3. **茶叶收藏 \+ 评论互动社区**：用户可收藏喜爱茶叶、发布评论，形成茶文化线上交流社区；

4. **茶馆线上预约支付一体化**：无需线下到店订座，用户线上一键预约茶座、完成支付，简化茶馆线下接待压力；

5. **可视化运营数据看板**：管理员后台内置饼图、柱状图，直观统计活动分类、茶馆销售订单数据，辅助运营决策；

6. **双端注册机制**：普通用户、茶馆商家独立注册表单，精准区分个人与店铺账号，业务隔离清晰。

### 6\.2 系统安全亮点

1. 用户、商家、管理员密码全部采用 MD5 不可逆加密存入数据库，杜绝明文泄露隐私；

2. JWT 无状态登录会话，设置固定过期时长，退出登录销毁前端 Token，防止账号劫持盗用；

3. 三层参数校验：前端表单校验 \+ 后端接口参数校验 \+ 数据库字段约束，拦截非法脏数据；

4. 严格角色接口拦截，用户无法访问商家 / 后台接口，商家仅能操作本店数据，权限隔离安全；

5. 文件上传安全校验：限制图片后缀格式与单文件大小，过滤恶意脚本上传风险。

### 6\.3 拓展迭代优势

1. 前后端完全解耦分层架构，便于后续拓展茶叶线上商城、活动报名收费、短信通知、人脸识别登录、茶文化视频播放模块；

2. 数据字典化管理：茶叶类型、活动类型后台可视化维护，新增分类无需改动后端代码；

3. 全列表多条件检索功能：茶叶、活动、茶馆、订单页面支持关键词搜索，快速定位目标数据；

4. 前台轻量化清新茶文化 UI，风格贴合传统茶行业，操作逻辑简单，中老年用户也可快速上手；

5. 全量数据永久归档：茶叶访问记录、收藏、预约订单、评论、活动记录全部留存，支持年度茶文化运营数据统计复盘。

## 七、项目总结

本《基于 SpringBoot\+Vue 茶文化推广系统》面向中华茶文化线上科普、线下茶馆数字化运营场景开发，采用前后端分离架构，解决传统茶文化传播渠道单一、茶馆线下订座繁琐、缺少线上茶叶展示与用户互动平台等痛点。系统划分普通用户、茶馆商家、系统管理员三类核心角色，完整实现茶文化线上科普、茶叶展示收藏、评论互动、线下茶活动浏览、茶馆茶座预约支付、后台可视化数据管控一体化功能；配套完善的 JWT 三角色鉴权、密码加密、接口权限拦截安全机制，保障用户、商家、平台数据安全。
项目代码分层规范，业务贴合茶文化传播与茶馆线上经营真实场景，既满足计算机专业毕业设计、课程设计交付标准，也可迭代新增茶叶电商、付费茶活动、短视频科普功能落地到文旅茶企、线下茶馆正式使用，具备优秀的实用性、可维护性与二次拓展开发空间。
