# Tea-Culture-Promotion-System
【万字文档+源码】基于SpringBoot+Vue茶文化推广系统项目-可用于毕设-课程设计-练手学习-学习资料分享-本文介绍了一个基于SpringBoot+Vue的茶文化推广平台开发项目。系统采用前后端分离架构，包含普通用户前台、茶馆商家和管理员后台三类角色。主要功能包括茶叶展示收藏、茶活动报名、茶馆预约、评论互动等，旨在数字化传播茶文化。后端使用SpringBoot+MyBatis-Plus+MySQL，前端基于Vue3+Element Plus实现。系统通过JWT进行鉴权，支持数据可视化统计，为传统茶文化提供线上展示和互动平台，简化茶馆运营管理流程。
